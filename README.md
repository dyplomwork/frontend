# SCXDROP (Frontend) — Vue 3 + Vite


## Запуск
```bash
npm install
npm run dev
```

## API 
Фронт використовує `VITE_API_BASE_URL` (див. `.env.example`).
Для проду апі буде:
- `https://`

Приклад `.env`:
```bash
VITE_API_BASE_URL=https://
```




## Сторінки
- `/` — головна
- `/login` — вхід
- `/plinko` — Plinko
- `/roulette` — Roulette
- `/cases` — Cases
- `/admin` — адмінка
